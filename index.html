Resumo do dia

Teste com os dados reais de novembro/2026 (até 25/11). Troque a data para ver outros dias; o que você lançar fica só neste aparelho.

Um dia ou um período (De/Até), lido da planilha: o estoque de cada produto, o fechamento dos motoristas (carregou = vendido + volta boa + volta ruim, que inclui trocas e defeitos) e a produção. Os painéis completos continuam na planilha.

Estoque

Estoque final = anterior + produção − saída + volta boa − perdas + ajustes. A volta ruim (com as trocas) não volta ao estoque; aparece só para conferência.

Configurar

No modo Demonstração, os lançamentos ficam só neste aparelho, para treinar. No modo Planilha, cada lançamento vira uma linha nas tabelas da planilha 6.x no OneDrive ou SharePoint.

Onde gravar
Esta é a prévia dentro do Claude: aqui só o modo Demonstração funciona. Para gravar na planilha, abra o site no endereço próprio da Gelo Minerale (veja o guia de instalação).
Vem do registro do aplicativo no Microsoft Entra ID (passo 1 ao lado).
Formato da planilha
Modelo antigo: grava no arquivo do mês (2026/11.xlsx) dentro da pasta EXPEDIÇÃO E PRODUÇÃO GELO, nas abas dos dias e na aba Produção.
No OneDrive: na pasta, Compartilhar → Copiar link (com permissão de edição). As fotos vão para Fotos/AAAA/MM dentro dela.
No OneDrive: Compartilhar → Copiar link (pessoas da Gelo Minerale com permissão de edição).
Lançamentos pendentes guardados quando a internet cai
Como ligar o site à planilha
  1. No portal do Azure (portal.azure.com), em Microsoft Entra ID → Registros de aplicativo → Novo registro: nome Gelo Minerale Lançamentos, contas só desta organização.
  2. Em Autenticação → Adicionar plataforma → Aplicativo de página única (SPA), com o endereço deste site como URI de redirecionamento:
  3. Em Permissões de API → Microsoft Graph → Delegadas: Files.ReadWrite.All e User.Read. Clique em "Conceder consentimento do administrador".
  4. Copie o ID do aplicativo e o ID do diretório da página Visão geral e cole aqui ao lado.
  5. Coloque a planilha 6.x no OneDrive ou SharePoint, compartilhe com quem vai lançar e cole o link aqui.
  6. Clique em Salvar e entrar, depois em Testar ligação. O teste lê os cadastros (produtos, pessoas, motivos) da própria planilha.
